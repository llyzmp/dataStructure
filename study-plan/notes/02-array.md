# 数组 — 连排座位

## 记忆锚
**画面锚：电影院连排座位** — 座位挨着排，每个有编号（索引），通过编号直接定位是 O(1)

## 核心特性
- **随机访问**：O(1) — 通过索引直接定位
- **连续内存**：元素在内存中连续存储
- **动态扩容**：JavaScript 数组是动态数组，自动扩容

## 扩容机制

### 翻倍扩容策略
```
初始容量：4
push(1-4)：不扩容，直接放
push(5)：容量 4 → 8，搬 4 个元素
push(9)：容量 8 → 16，搬 8 个元素
push(17)：容量 16 → 32，搬 16 个元素
```

### 复杂度分析
- **总搬运量**：4 + 8 + 16 + ... ≈ 2n → O(n)
- **均摊到每次 push**：O(1)

## 关键概念：均摊复杂度

**push 是均摊 O(1)，不是每次 O(1)**

- 绝大多数时候：直接坐空位 → O(1)
- 偶尔全搬：触发扩容 → O(n)
- 平均下来：每次 push 就像 O(1) 一样

## 基本操作复杂度

| 操作 | 坐座位比喻 | 复杂度 | 原因 |
|------|-----------|--------|------|
| `arr[3]` | 找 3 号座位的人 | O(1) | 随机访问，直接定位 |
| `arr.push(x)` | 最后一排后面加个座 | O(1) | 均摊复杂度 |
| `arr.pop()` | 最后一排的人直接走 | O(1) | 不用移动 |
| `arr.shift()` | 第一个人走，后面全部往前挪 | O(n) | 全部移动 |
| `arr.unshift(x)` | 所有人往后挪一位，新来的坐第一 | O(n) | 全部移动 |
| `arr.splice(2, 1)` | 3 号座的人走，后面全部往前补 | O(n) | 全部移动 |

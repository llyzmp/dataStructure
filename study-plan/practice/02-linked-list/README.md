# 概念 2：链表 — 学习指南

## 画面锚：寻宝接力
- 每张纸片知道下一张在哪，但没有地图，只能一张一张往下找
- 节点结构：`{ val, next }`
- 查找：O(n) — 必须从头遍历
- 增删（已定位）：O(1) — 改指针即可

## 核心知识点

### 1. 链表 vs 数组

| 场景 | 链表 | 数组 | 谁赢 |
|------|------|------|------|
| 随机访问 | O(n) | O(1) | 数组 |
| 已定位 + 删末尾 | O(1) | O(1) | 平手 |
| 已定位 + 删中间 | O(1) | O(n) | 链表 |
| 需查找 + 删中间 | O(n) | O(n) | 平手 |

### 2. 常见技巧
- **哑节点（Dummy Node）**：简化头节点的边界处理
- **快慢指针**：找中间节点、检测环
- **三指针法**：反转链表

## 必刷题（3 道）

### 题 1：#206 反转链表 ⭐⭐⭐
- 文件：`01-reverse-linked-list.js`
- 方法：三指针法（存 → 转 → 移 → 移）
- 复杂度：O(n) 时间，O(1) 空间

### 题 2：#21 合并两个有序链表 ⭐⭐
- 文件：`02-merge-two-sorted-lists.js`
- 方法：双指针 + 哑节点
- 复杂度：O(n + m) 时间，O(1) 空间

### 题 3：#141 环形链表 ⭐⭐
- 文件：`03-linked-list-cycle.js`
- 方法：快慢指针（Floyd 判圈）
- 复杂度：O(n) 时间，O(1) 空间

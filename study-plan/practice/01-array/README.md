# 概念 1：数组 — 学习指南

## 画面锚：电影院连排座位
- 座位挨着排，每个有编号（索引）
- 通过编号直接定位 → O(1)
- 插入/删除中间的人 → 后面所有人要挪 → O(n)

## 核心知识点

### 1. 数组的内存结构
- 连续存储：元素在内存中挨着放
- 随机访问：通过索引直接计算地址 → O(1)

### 2. 动态数组扩容
- **翻倍策略**：容量不够时，分配 2 倍大小的新数组，把旧数据搬过去
- **均摊复杂度**：push 是均摊 O(1)，不是每次 O(1)

### 3. 基本操作复杂度

| 操作 | 复杂度 | 原因 |
|------|--------|------|
| `arr[i]` 访问 | O(1) | 索引直接定位 |
| `arr.push(x)` | O(1) | 均摊，末尾添加 |
| `arr.pop()` | O(1) | 末尾删除 |
| `arr.shift()` | O(n) | 头部删除，全部前移 |
| `arr.unshift(x)` | O(n) | 头部插入，全部后移 |
| `arr.splice(i, 1)` | O(n) | 中间删除，后面全移 |

- 文件：`01-remove-duplicates.js`
- 方法：快慢指针
- 复杂度：O(n) 时间，O(1) 空间

- 文件：`02-merge-sorted-array.js`
- 方法：从后往前双指针
- 复杂度：O(m + n) 时间，O(1) 空间

### 题 3：#283 移动零 ⭐
- 文件：`03-move-zeroes.js`
- 方法：快慢指针 + 交换
- 复杂度：O(n) 时间，O(1) 空间

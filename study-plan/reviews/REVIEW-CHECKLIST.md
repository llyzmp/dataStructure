# 复习检查清单

## 复习方法

### R1 回忆测试（+1天）
- [ ] 闭眼回忆画面锚
- [ ] 口述核心操作和复杂度
- [ ] **不看任何代码**

### R2 闭卷默写（+3天）
- [ ] 不看代码手写 JS 实现
- [ ] 做第 1 道必刷题
- [ ] 代码能跑通

### R3 换题练习（+7天）
- [ ] 做一道没做过的新题
- [ ] 不要重复做过的题
- [ ] 能独立解出

### R4 费曼讲解（+14天）
- [ ] 假装教别人讲原理
- [ ] 讲实现细节
- [ ] 讲应用场景
- [ ] 流畅讲完无卡壳

### R5 终极检验（+30天）
- [ ] 做新题
- [ ] 30 秒说出思路
- [ ] 快速解题 = 掌握
